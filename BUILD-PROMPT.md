## 2. Заставка при входе (желание Остапа)

Остап хочет короткую анимацию при входе в чёрно-золотом стиле логотипа. Сделай её так, чтобы правила не пострадали.

- Заставка и есть авторский момент движения на странице (rules.md, раздел 8) или его начало. Второго большого
  эффекта не делай.
- Материал — монограмма HS, где S нарисована прядью волос. Хорошо, если заставка вырастает из этой пряди, а не
  просто проявляет логотип. Это подсказка, а не требование.
- **Вектора логотипа нет.** Есть только `content/photos/best/brand/logo-avatar.jpg` (150×150) и объёмный логотип на
  стене: `team/03-kolorysty_040_2026-10-28.jpg`, `interior/2026-11-03_DfSUsXysL4-_01.jpg`. Перерисуй монограмму
  в SVG вручную и сверь с оригиналом наложением на увеличенном рендере. В журнале запиши, что это перерисовка для
  концепта, а не официальный вектор.
- Требования:
  - показывается один раз за сессию (`sessionStorage` в try/catch), на `/tsiny/` при переходе её нет;
  - длится не больше 1,5–2 с, любой клик, тап или клавиша её пропускает;
  - не ждёт загрузки и не рисует проценты: первый кадр грузится под ней параллельно, с `fetchpriority="high"`;
  - без JS и при `prefers-reduced-motion: reduce` заставки нет, страница видна сразу;
  - заставка переходит в первый экран (например, монограмма уходит в шапку), а не просто гаснет поверх;
  - `aria-hidden`, фокус не перехватывает;
  - LCP на телефоне замерь с ней и без неё. Если она его заметно ухудшает, укорачивай.

## 3. Фото и видео

По словам Остапа, фото дают 30–40 % впечатления о салоне. Качество кадра важнее количества.

Где искать, по порядку:
1. `content/photos/best/` (118 отобранных кадров). Смотри контактными листами по 15–20 кадров.
2. Полный архив `content/instagram/posts/` и `highlights/` (1 213 jpg, 724 mp4).
3. **Кадры из видео.** Reels сняты в новом зале в 1080×1920. Вытаскивай лучшие кадры через ffmpeg (установлен,
   версия 9). Общих планов зала без текста среди фото нет, а в видео они есть. Бери кадры без наложенного текста.
4. Видео на сайте ставь, только если оно что-то доказывает (процесс окрашивания, результат в движении): короткий
   немой цикл, сжатый ffmpeg, с постером, в стартовый вес на телефоне не входит.
5. AI-обработка, раздел 4.
6. Instagram владелицы @_olga_hubska через Playwright, только если для блока «Власниця» не хватит кадров.

У каждого кадра на сайте должна быть роль, которую можно сказать одной фразой. Журнал происхождения веди в
`src/assets/SOURCES.md`: файл, источник (пост, хайлайт или видео с таймкодом), что сделано (кроп; AI-правка какой
моделью и что именно), путь к оригиналу. `content/` не трогай, рабочие копии клади в `src/assets/`.

## 4. AI-обработка через OpenRouter

Ключ Остап даст в чате. Положи его в `.env` как `OPENROUTER_API_KEY` (`.env` уже в `.gitignore`). Ключ не попадает
ни в код сайта, ни в логи, вызовы идут только из локальных скриптов в `scripts/`. Модель выбери по актуальному
списку (`GET https://openrouter.ai/api/v1/models`, нужны модели с выходом image) и по документации OpenRouter
о генерации изображений. Известные мне ID могли устареть: `google/gemini-3-pro-image-preview` (Nano Banana Pro),
дешевле `google/gemini-2.5-flash-image`.

**Основной режим, можно:**
- апскейл и чистка шума;
- убрать текст сторис, стикеры, логотип MC с накидок, неон «Mon Cheri»;
- дорисовать фон по краям под нужное кадрирование.

**Только при явной нехватке материала** (так решил Остап):
- сгенерировать деталь зала без людей (орхидея, мрамор, латунные полки, арочное зеркало), опираясь на реальные кадры
  зала. Такой кадр помечается в журнале как сгенерированный, не стоит рядом с утверждением о конкретной работе
  и показывается Остапу отдельным списком на остановке 2.

**Нельзя никогда:**
- менять цвет, оттенок, форму и состояние волос. Результат окрашивания и до/після — доказательство работы салона,
  правка здесь равна выдумке;
- трогать лица, кожу, фигуру. В PRODUCT.md AI-портреты с пластиковой кожей прямо названы анти-референсом;
- генерировать людей, работы, клиенток или зал целиком.

После каждой правки сравни результат с оригиналом при 100 %. Пластиковая кожа, лишние пальцы, кривые буквы, поплывшие
пряди — откатывай. Перед первым платным вызовом назови модель и цену за кадр. До остановки 1 допускается только
проба на 2–3 кадрах, остальное обрабатывай после утверждения плана.
